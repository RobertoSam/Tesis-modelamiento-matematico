2. Autocorrelación, correlaciones y tamaño muestral efectivo (apunte 3)

  • ACF: estimador de stats::acf de R (serie centrada en su media, divisor \(n\) en todos los rezagos), en los rezagos 1, 3, 6, 12 y 24.
  • Tamaño muestral efectivo por par [VERIFICAR: fuente de la fórmula; propuesta para el bibliotecario]: \(1/n_{\text{ef}} = 1/n + (2/n)\sum_{j=1}^{J} \frac{n-j}{n}\,\rho_x(j)\,\rho_y(j)\), con \(J = \lfloor n/5 \rfloor\) y \(n_{\text{ef}} \le n\). Prueba t bilateral de \(\rho = 0\) con \(n_{\text{ef}} - 2\) grados de libertad; con \(n_{\text{ef}} \le 3\) no se evalúa (cuenta como no significativa).
  • En niveles, además, las correlaciones entre las series sin su tendencia lineal (insumo del apunte 10).
def tabla_n_ef(M, version):
    n = M.shape[0]
    R = np.corrcoef(M, rowvar=False)
    filas = []
    for a in range(M.shape[1]):
        for b in range(a + 1, M.shape[1]):
            r = R[a, b]
            ne = n_efectivo(M[:, a], M[:, b])
            p_n, s_n = prueba_correlacion(r, n)
            p_e, s_e = prueba_correlacion(r, ne)
            filas.append({'version': version, 'serie_a': NOMBRES[a], 'serie_b': NOMBRES[b], 'r': r, 'n': n,
                          'n_ef': ne, 'p_n': p_n, 'p_n_ef': p_e, 'signif_n': s_n, 'signif_n_ef': s_e})
    return pd.DataFrame(filas)


def resumen_n_ef(tb):
    return {'n': int(tb['n'].iloc[0]), 'n_ef_mediana': tb['n_ef'].median(), 'n_ef_min': tb['n_ef'].min(),
            'n_ef_max': tb['n_ef'].max(), 'prop_signif_n': tb['signif_n'].mean(),
            'prop_signif_n_ef': tb['signif_n_ef'].mean()}


def mapa_calor(Rdf, titulo, ruta):
    fig, ax = plt.subplots(figsize=(9, 7.5))
    im = ax.imshow(Rdf.to_numpy(), cmap='RdBu_r', vmin=-1, vmax=1)
    ax.set_xticks(range(len(Rdf)), Rdf.columns, rotation=60, ha='right', fontsize=7)
    ax.set_yticks(range(len(Rdf)), Rdf.index, fontsize=7)
    for i in range(len(Rdf)):
        for j in range(len(Rdf)):
            if i != j:
                ax.text(j, i, f'{Rdf.iat[i, j]:.2f}'.replace('.', ','), ha='center', va='center', fontsize=5)
    fig.colorbar(im, ax=ax, shrink=0.8, label='r')
    ax.set_title(titulo, fontsize=10)
    fig.tight_layout()
    fig.savefig(ruta, dpi=130)
    plt.close(fig)

6. Regresión sobre el tiempo y análisis de residuos (apunte 11, regla D5)

Especificación fijada antes de calcular (D5, 20-10-2026), constantes de src/series_tiempo.py:

def dif_max(a, b):
    """Diferencia máxima relativa |a - b| / max(1, |b|): absoluta para valores de magnitud <= 1."""
    a, b = np.asarray(a, dtype=float), np.asarray(b, dtype=float)
    return float(np.max(np.abs(a - b) / np.maximum(1, np.abs(b))))
